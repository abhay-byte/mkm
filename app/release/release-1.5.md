# Changelog - MKM v1.5

## Version 1.5 (June 2026)
### 🔧 Bug Fixes & Improvements

#### Battery Monitoring Enhancements
* Restored and fixed mAh capacity display in notifications and session history.
* Fixed live drain percentage calculation to update properly in real-time (without needing screen state toggles).
* Fixed charging ETA calculation to work reliably across devices by deriving current from real wattage when hardware sensors report poorly.
* Cleaned up UI by removing duplicate notification toggles from the Battery screen and centralizing them in Settings.
