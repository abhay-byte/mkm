# Minimal Kernel Manager v1.7

v1.7 polishes the Home and Overlay experience and ships a long list of small but useful improvements.

## What's New

### 🏠 Home Page
- **Quick Access grid** for one-tap navigation to every component in the app.
- **Lock badges** on tiles that need root or Shizuku (CPU, GPU, RAM, Storage, Power) — the same access model you already see in the side drawer.

### 📊 Overlay
- **Absolute Values display** with per-metric toggles for CPU, GPU, RAM, and SWAP. Show actual GHz and GB instead of percentages when you want them.
- **CPU Frequency Display** selector: All Cores, Average, or Max Frequency.
- **Accent color can now tint the background** with a separate background color picker, so you can mix and match the icon color and the card tint.

### ⚙️ Settings
- **Discord community card** at the bottom of the page to join the MKM Discord in one tap.

### 🐛 Fixes
- The overlay no longer reports "active" after a force close. It now auto-resumes on app start if you had it on, or resets the stale flag if overlay permission was revoked.
- GPU frequency on Adreno / Turnip devices shows `N/A` with a "root needed" hint instead of a misleading `0` — the kernel blocks shell access on modern Android, and only root unlocks live GPU frequency.

## Installation

Download the `app-release.apk` below and install it on your Android device (Android 7.0+ required).

**Note:** Root access or Shizuku is required for most advanced features.
