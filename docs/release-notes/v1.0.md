# Minimal Kernel Manager v1.0

We are excited to announce the first release of **Minimal Kernel Manager (MKM)**!

MKM is a powerful Android kernel management and system monitoring application designed for advanced users and enthusiasts.

## 🚀 Key Features

### 📊 Real-Time Performance Overlay
- Customizable floating overlay with always-on-top system monitoring
- Monitor CPU, GPU, RAM, Swap, Power, and Thermals
- Real-time sparkline graphs
- Drag-and-drop component reordering

### 💾 Persistent Swap Management
- Create persistent swap files
- Automatic activation on boot
- Supports both Root and Shizuku access

### ⚙️ System Control
- **CPU**: Per-cluster frequency and governor control
- **GPU**: Frequency and governor management
- **Thermal**: Detailed temperature tracking

### 🎨 Modern UI
- Built with Jetpack Compose and Material Design 3
- Dynamic dark theme
- Optimised for Android 15

## Installation

Download the `app-release.apk` below and install it on your Android device (Android 7.0+ required).

**Note:** Root access or Shizuku is required for most advanced features.
