# Minimal Kernel Manager v1.8

v1.8 brings in-memory FPS Session Recording with hardware GPU frame collectors, fixes Overlay update frequency controls, and resolves power/battery charge polarity across the app.

## What's New

### 📈 FPS Recording & GPU Metrics (GH-16)
- **FPS Session Recording**: Record frame rate sessions in-memory with a live canvas graph (`FpsRecordGraph`) showing FPS trends, min/max/average stats, total samples, and elapsed time.
- **Hardware GPU Frame Collectors**: Root-level ftrace kernel event counting for **Snapdragon/Adreno** (`adreno_cmdbatch_submitted` inflight drop counting) and **MediaTek/Mali** (`dma_fence_signaled` timeline event counting).
- **Non-root Fallback**: Fallback to `FpsMonitor` with a guaranteed 2-second sampling cadence and automatic fallback lock-in after consecutive failures.
- **Session Safety**: Ghost session prevention (recording gated on active overlay) and cleanup on cancellation or app stop.

### ⏱️ Overlay Update Frequency (GH-17)
- **Honest Update Interval**: The Overlay update frequency slider (500 ms – 5000 ms) now directly drives the overlay monitor loop.
- **500 ms Floor**: Dropped the old 1000 ms FPS-off floor so the overlay can update smoothly at 500 ms intervals.

### ⚡ Power & Battery Polarity (GH-15)
- **Signed Power Metrics**: Charging and discharging power wattage/current polarity (`+/-` sign) corrected across Overlay PWR, Power Screen, Battery Screen, Settings, and Notifications.
- **Instant Plug Invalidation**: Plug and unplug events immediately bust cached snapshots and invoke real-time update ticks.

### 🌐 Localization & Quality
- **Simplified Chinese (`zh-rCN`)**: Full translations for all newly added FPS recording, overlay interval, and power metrics.
- **Unit Testing**: Comprehensive test suites for `FpsSessionRecorder` and `BatteryCharging`.
